#  Get Started !!!
Step 1 : Copy and paste the following command to clone the repository:
```bash
git clone https://github.com/codewithdika/docker-with-termux-android.git
```
Step 2 : Follow / Copy This Command:
```bash
cd docker-with-termux-android
chmod +x setup-qemu.sh
./setup-qemu.sh
```
📋 **Pro Tip:** You can copy the command by selecting it and pressing `Ctrl+C` (or `Cmd+C` on macOS).
